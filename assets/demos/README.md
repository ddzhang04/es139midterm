# Doodle tree asset

`doodle-tree.png` was generated with the built-in image generation tool, then edited to remove its background. It is a transparent 2D sprite for the placeable AR demo.

Style prompt: deliberately crude mouse drawing, crooked brown trunk, oversized green canopy, shaky black outlines, white gaps, stray scribbles, no shading, text, face, or extra objects.

Final edit prompt: remove only the white background, including white gaps within the scribbles; preserve the wonky trunk, green canopy, black outlines, stray strokes, colors, and proportions; output a transparent PNG cutout for an AR sprite.
